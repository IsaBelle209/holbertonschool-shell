# Shell, init files, variables and expansions

This project introduces shell aliases, variables, expansions and arithmetic.

- 0-alias: Creates an alias for ls that removes regular files.
- 1-hello_you: Prints hello followed by the current user.
- 2-path: Adds /action to the PATH environment variable.
- 3-paths: Counts the directories in PATH.
- 4-global_variables: Prints environment variables.
- 5-local_variables: Lists shell variables and functions.
- 6-create_local_variable: Creates a local variable named BEST.
- 7-create_global_variable: Creates an exported variable named BEST.
- 8-true_knowledge: Adds 128 to the value of TRUEKNOWLEDGE.
- 9-divide_and_rule: Divides POWER by DIVIDE.
- 10-love_exponent_breath: Raises BREATH to the power of LOVE.
- 11-binary_to_decimal: Converts a binary number to decimal.
- 12-combinations: Prints combinations of two lowercase letters, excluding oo.
- 13-print_float: Prints NUM with two decimal places.
- 14-decimal_to_hexadecimal: Converts DECIMAL to hexadecimal.
